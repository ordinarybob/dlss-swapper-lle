# Security and safe use

LLE replaces DLLs inside selected game installations. Use trusted component
sources, close affected games before updating, and retain the `.dlsss` backups.
Game updates, file verification and anti-cheat systems may reject modified files.

Run LLE as the user who owns the game library. Do not elevate it merely to bypass
a permissions error. If a Streamline operation reports interrupted work, use its
recovery action before making another change to those components.

## Maintenance and reporting

There is no ongoing security-maintenance commitment or private reporting service.

Do not post credentials, private paths, raw application databases or unredacted
logs in public reports. LLE-specific problems belong to this fork, not the
upstream project's support channels.
