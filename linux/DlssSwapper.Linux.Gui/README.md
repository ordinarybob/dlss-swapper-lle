# DLSS Swapper LLE Linux desktop

The Avalonia desktop application shares its saved game library and component
operations with the Linux CLI.

See the [Linux guide](../README.md) for installation, launcher discovery,
game import, updates and platform requirements. The [feature list](../../docs/FEATURE_CLUSTERS.md)
covers the interface and workflows; [building from source](../../docs/BUILDING.md)
covers development and packaging.
